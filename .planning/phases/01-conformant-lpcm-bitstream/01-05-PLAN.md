<objective>
Implement the four descriptor OBUs — IA Sequence Header, Codec Config, Audio Element, Mix
Presentation — and the four distinct layout types they carry, reproducing the complete 120-byte
descriptor prologue of `test_000003.iamf` byte-exact from its published configuration.

Purpose: descriptors are the bulk of the phase's byte surface and where the format's asymmetries
live. `sample_format_flags == 0` means **big**-endian, the opposite of a WAV-shaped assumption.
Every sub-mix must carry a stereo layout, hard-checked on write by `iamf-tools` and unchecked on
read. `additional_profile` must be at least `primary_profile`, checked by `libiamf` and unchecked by
`iamf-tools` — the reverse of the usual strictness asymmetry. Each of those is a clean-decode,
wrong-result failure if missed.

Output: `src/obu/{sequence_header,codec_config,audio_element,mix_presentation}.rs`,
`src/model/layout.rs`, and a hand-decoded vector suite covering every field in the prologue.
</objective>

<assumption_delta_decision>
**Noun:** `AudioElementType`
**Decision:** `promote`

The generalized type — one enum in which **every wire value is representable** — becomes primary, and
the specific `ChannelBased` case is demoted to one variant of it. The alternative shape, keeping a
channel-based type primary and adding the general case alongside it, is rejected.

**Rationale.** Decode is a superset of encode. The encoder emits beds only, but Parallax's import
adapter meets foreign files, and `IO.md` §1 specifies importing scene elements as Ambisonic clips.
Modelling the encoder's shape as primary would leak the encoder's narrower assumption into the import
path, where it is wrong. `Reserved { value, raw }` buys a **testable property** rather than mere
forward compatibility: decode-then-encode of an element we do not understand is byte-identical, which
is CI-checkable against fixtures nothing else in the crate can assert on, and strictly stronger than
"we parsed it". It also matches Parallax's house rule — the adapter can say "this file carries
element type 3, which we do not model" instead of rejecting the whole file or letting it pass as
opaque bytes.

**Note on the detector's own signal.** The assumption-delta detector fired on the term "multiple" in
*"a total sample count that is not a multiple of the frame size"* — arithmetic, not pluralization.
That match is a **lexical false positive** and no checkpoint is built around it. The genuine delta is
the one recorded above, and it was identified by reading the decisions, not by the lexical trigger.

**Companion invariant test.** Task 3 lands the property this decision exists to buy: every wire value
in the reserved range round-trips byte-identically through `Reserved { value, raw }`. That test goes
red the instant a future phase reintroduces the channel-only assumption.
</assumption_delta_decision>

  Emitting both equal is always safe.

  states.** The first Audio Frame begins at offset `0x78`. The field-by-field table in RESEARCH.md
  accounts for all 120 bytes and this plan's vectors reproduce them.
