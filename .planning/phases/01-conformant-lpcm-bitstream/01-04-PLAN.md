<objective>
Implement the OBU header and the common framing every OBU type in the format shares: byte 0 MSB-first,
the two-pass `obu_size` origin, the trimming fields in their counter-intuitive END-then-START order,
the extension header, the central `trailing` drain, and `find_obu_boundaries()`.

Purpose: this is where the phase's one factually wrong requirement gets corrected before it can do
damage. OBU-03 as written models bit 6 as a four-variant polymorphic enum; at the pinned v1.1.0-exact
tree it has **two** variants, and getting this wrong shifts every descriptor payload by two bytes on
the pinned decoder with no error and no crash. Also: `find_obu_boundaries()` is written **before the
first encoder test**, so the always-on offline layer has 200+ real reference files to walk from the
moment it exists.

Output: `src/obu/header.rs` and `src/obu/boundaries.rs`, hand-decoded vectors for both, the offline
reference-corpus walk, and an amended `REQUIREMENTS.md`.
</objective>

<research_corrections_owned_here>
**Correction 1 — OBU-03 as written mirrors a draft-v2.0.0 tree. This is decision-changing and it
blocks this plan.** It is owned here in full, and Task 4 amends the requirement text so the
correction is visible in `REQUIREMENTS.md` rather than silently applied in code.

REQUIREMENTS.md OBU-03 says bit 6 is *"a polymorphic enum carried by the payload variant … trimming
status for audio frames, inverted `is_not_key_frame` for temporal delimiter, reserved-SHALL-be-0
elsewhere"*. `PITFALLS.md` §2 adds `optional_fields_flag` for Mix Presentation and gives a
four-variant enum. PROJECT.md's Context repeats it.

At `iamf-tools` **v2.1.0** the field is named `obu_trimming_status_flag` and
`IsTrimmingStatusFlagAllowed()` returns true **only for Audio Frames** — types `kObuIaAudioFrameId0`
through `kObuIaAudioFrameId17` and `kObuIaAudioFrame`. Setting it on a Temporal Delimiter is an
`InvalidArgumentError` from `Validate()`. A repository-wide grep for `type_specific_flag`,
`GetIsKeyFrame`, `GetOptionalFieldsFlag`, `is_not_key_frame` and `optional_fields_flag` over
`iamf/obu/` at v2.1.0 **returns nothing**; the same grep at `main` returns all of them, and `main`'s
own comment reads "In IAMF v2.0.0, if `optional_fields_flag` is true…". `PITFALLS.md` read `main`.

**The second, independent reason this matters.** `libiamf@v1.1.0`'s `IAMF_OBU_split` reads the trim
fields whenever the header bit is set, **for any OBU type** — `main` guards it with an
audio-frame check but the tree we pin does not. So bit 6 set on a descriptor OBU shifts that
descriptor's entire payload by two bytes on the decoder whose acceptance is the Core Value. Silent,
catastrophic, and invisible to a test suite that only round-trips against itself.

`obu_redundant_copy`, by contrast, is exactly as OBU-04 documents: forbidden on types 3, 4, 5 and
6..=23, allowed elsewhere. OBU-04 stands unchanged.

Also owned here, from correction 5: the reference file's descriptor prologue is **120 bytes** and the
file walks **67 OBUs** to `bytes.len()` exactly — both numbers are used by this plan's boundary tests.

  <action>
Extend `write_obu` and `read_obu_header` with the after-size fields, the legality rules and the
trailing mechanism, keeping every write immediately adjacent to its read.

**Trim field order.** `WriteFieldsAfterObuSize` writes, in order: `num_samples_to_trim_at_end`, then
`num_samples_to_trim_at_start` (both only when the trimming flag is set), then
`extension_header_size` plus `extension_header_bytes` (only when the extension flag is set). END
before START is the opposite of intuition and is byte-identical whenever the two values are equal —
which is almost always — so the differing-value test is the only thing that can catch a swap. Put a
`// NOTE:` beside the write pair saying exactly that, because the next person to read this code will
assume it is a typo.

**Legality, enforced at construction and at write.** `IsTrimmingStatusFlagAllowed` returns true only
for `AudioFrame` and `AudioFrameId0..=AudioFrameId17`; `write_obu` returns
`ErrorKind::TrimmingFlagNotAllowed` otherwise, and the doc comment on that check records the
`libiamf@v1.1.0` consequence — its splitter reads trim fields for **any** type whose bit 6 is set, so
an illegal flag on a descriptor shifts that descriptor's payload two bytes with no error from either
side. `IsRedundantCopyAllowed` is false for types 3, 4, 5 and 6..=23 and true elsewhere;
`write_obu` returns `ErrorKind::RedundantCopyNotAllowed` on breach. Both checks cite
`iamf/obu/obu_header.cc` at v2.1.0.

**Extension header.** `extension: Option<Vec<u8>>` on `ObuHeader`. Writing emits
`write_uleb128_minimal(bytes.len())` then the bytes. Reading, when the flag is set, reads the
uleb128 then **bounds-checks the length against `bytes_remaining()` before reserving** — same rule as
every other count in the format. The flag itself is derived from `extension.is_some()`, never stored.

**The trailing drain and D-05's precedence rule.** `trailing: Vec<u8>` lives on each OBU struct from
its first commit (OBU-07) and is drained centrally in `src/obu/mod.rs`'s read wrapper: after the
type-specific parser returns, whatever remains in the payload `sub_reader` becomes `trailing`.
Document D-05's precedence explicitly here, because two mechanisms will otherwise both claim
"everything after the fields I understood": `trailing` is the **OBU-level** remainder, and a
payload-level raw-bytes field (which plan 01-05 introduces for an unmodelled Audio Element type)
consumes to the end of *its own* payload, leaving `trailing` empty. Without that rule the boundary is
ambiguous and Phase 2's round-trip property becomes untestable. Serialisation appends `trailing`
**last**, after the type-specific payload.

**The size ceiling.** `kEntireObuSizeMaxTwoMegabytes` is `1 << 21`; the derived bound is
`(1 << 21) - 1 - size_of_obu_size`. Compute it with checked arithmetic and return
`ErrorKind::ObuTooLarge` above it, matching `GetObuSizeAndValidate`.

Extend `tests/obu_header.rs` with a named test per behaviour, each citing the offset in
`test_000003.iamf` it reproduces where one exists, and each expected byte string written by hand
before the code that produces it.
