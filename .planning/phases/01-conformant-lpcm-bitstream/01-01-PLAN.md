  <action>
Create `src/error.rs` holding the whole public error surface, then re-export it from `src/lib.rs`.

`Location` is `#[non_exhaustive] pub enum Location { InputOffset(u64), OutputOffset(u64),
Field(&'static str), Unlocated }`, deriving `Debug, Clone, Copy, PartialEq, Eq`. `InputOffset` is
the position in the bytes being read; `OutputOffset` the position in the bytes being written;
`Field` a static field path for `validate()`; `Unlocated` for errors with no meaningful position.
Document that keeping the three sources distinguishable is the point — a single numeric `offset`
would conflate them.

`ErrorKind` is `#[non_exhaustive] pub enum ErrorKind` deriving `Debug, Clone, PartialEq, Eq` and
`thiserror::Error`, with one `#[error("...")]` message per variant. Seed it with the variants the
rest of Phase 1 already needs, each carrying only scalar payloads so the size budget holds:
`UnexpectedEndOfInput`, `NotByteAligned`, `Leb128TooLong`, `Leb128ValueTooLarge`,
`StringNotTerminated`, `StringTooLong`, `ObuSizeOverflow`, `ObuTooLarge`, `TruncatedObu`,
`UnalignedAfterSizeFields`, `RedundantCopyNotAllowed`, `TrimmingFlagNotAllowed`,
`ReservedValue { value: u8 }`, `LoudnessOutOfRange`, `ProfileNotFound`,
`ChannelCountExceedsProfile`. Do not add `#[from]` conversions — a blanket `From` loses the offset,
and D-08 requires conversion at the call site.

`Error` is `#[derive(Debug, Clone, PartialEq, Eq)] pub struct Error { kind: ErrorKind, at: Location }`
with `pub fn new(kind: ErrorKind, at: Location) -> Self`, `pub fn kind(&self) -> &ErrorKind`, and
`pub fn at(&self) -> Location`. Implement `Display` so the rendered string is the kind's message
followed by an offset or field fragment when `at` is not `Unlocated`, and implement
`std::error::Error` with `source()` returning `None`. Add the compile-time budget assertion as a
