<objective>
Build the bit-level I/O layer by hand — `BitCursor` and `BitWriter` over `&[u8]`, plus uleb128 in
both directions — and prove it against hand-computed vectors first and a differential oracle second.
This is the only module in the crate that knows what a bit offset is, and every `Error.at` value in
every later plan flows out of it.

Purpose: D-01 chose hand-rolling over wrapping a crate, and the reason it is defensible is the
oracle. A hand-rolled cursor that ships unchecked through the phase that matters most is the worst
of both worlds; a hand-rolled cursor cross-checked bit-for-bit against 50M downloads of exercise is
strictly better than either alternative. Land the oracle here, not in Phase 2.

Output: `src/bits/` with a read/write pair per primitive in the same file in that order, the
hand-computed vector suite BITS-06 requires before any OBU type exists, the proptest oracle, and

immediately followed by its `write_*` counterpart so asymmetry stays visible. Mirror the reference's

Signed reads are two's-complement over the requested width: read the width as unsigned, then
sign-extend from bit `width - 1` using checked shifts. Return `i64` and let callers narrow; a
9-bit field does not fit `i8` and a signed-16 field is what `audio_roll_distance`,
`integrated_loudness`, `digital_peak` and `default_mix_gain` all are, always big-endian on the wire.

`read_string` reads bytes until a NUL, inclusive, capped at 128 bytes **including** the NUL. Return
the bytes as a `Vec<u8>`, not a `String`: the wire carries a byte string and validating it as UTF-8
would make the parser stricter than the reference on read. A 128-byte run with no NUL is
`ErrorKind::StringNotTerminated`; a caller-supplied string longer than the cap on write is
`ErrorKind::StringTooLong`. Both carry a `Location`.

`read_uint8_span(n)` must **check `n` against `bytes_remaining()` before reserving anything**. This
is the V5 Input Validation control and the single most likely fuzz finding in a bitstream parser: a
length field is attacker-controlled, and allocating on it before bounds-checking is the OOM. The
same rule applies to every count-driven loop in every later plan — one rule, every count in the
format — so state it in a module-level comment here where it is first enforced.

`sub_reader(len_bytes)` returns a `BitCursor` borrowing exactly `len_bytes` of the parent's remaining
input and advances the parent past them. It requires byte alignment and errors with
`ErrorKind::NotByteAligned` otherwise. This is the mechanism Pattern 3 uses to give every OBU payload
a bounded view and to catch under-reads, which are otherwise silent.

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| caller-supplied `&[u8]` → `BitCursor` | Every length, count and width the parser acts on originates in attacker-shaped bytes. This is the crate's primary attack surface and the module a fuzzer reaches in microseconds. |
| `BitWriter` → caller-supplied values | Widths and values come from the model; a width larger than the value type or a value exceeding its width must be an error, not a silent truncation. |
