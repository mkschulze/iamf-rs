`pub fn lufs_to_q7_8(lufs: f64) -> Result<Q7_8>`.

The implementation is: reject NaN and both infinities first; multiply by `256.0`; apply
`round_ties_even`; range-check against `i16::MIN as f64 ..= i16::MAX as f64`; then convert. Do **not**

zero and biases every negative value upward by up to one LSB, and every loudness value in a real file
is negative. Order matters: range-check before converting, so an out-of-range input is a typed error
rather than a saturating cast.

it is not a transcendental and does not belong on the `disallowed-methods` list. Record that D-21
turns the guard into a **census whose correct answer is exactly one**, and that a second escape
