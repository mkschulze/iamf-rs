<objective>
Implement the three time-varying OBU types and the channel→substream packing that decides what goes
into each Audio Frame: Audio Frame with implicit substream ids and final-frame trimming, Temporal
Delimiter, Parameter Block with its `ParamDefinition` supplied explicitly, and the BCG packer.

Purpose: PROJECT.md names BCG channel→substream packing as **the highest silent-failure risk in this
phase**. Get it wrong and you get a clean decode with scrambled channels: no error, no crash, correct
byte count. Research closed it three independent ways — the reference's own ordering comment, the
`decoding_map` arithmetic in the layout table, and a shipped 5.1 file's own OBU size signature — so
this plan implements a known answer and proves it against all three.

Output: `src/obu/{audio_frame,temporal_delimiter,parameter_block}.rs`, `src/packing.rs`, and
hand-decoded vectors for each, plus the packing cross-check against a real 5.1 file.

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| caller-supplied PCM and channel count → the packer | A channel count disagreeing with the layout would produce short or long frames the decoder mis-frames. |
| caller-supplied frame payload bytes → the Audio Frame parser | `libiamf` performs **no** payload-level rejection on an audio frame; everything is caught downstream or not at all. |
| a Parameter Block's own length fields → the subblock loop | `num_subblocks` and per-subblock sizes are attacker-controlled counts driving allocation. |
