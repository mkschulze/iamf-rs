# Phase 4 Plan 01: Static Builder and Deterministic Manifest

> **For agentic workers:** REQUIRED SUB-SKILL: Use `superpowers:executing-plans` task-by-task. Keep the checkbox state truthful and commit each task independently.

**Goal:** Add a host-independent, immutable static-configuration builder that returns deterministic IAMF wire IDs and a correct sequence-global profile.

**Architecture:** `src/encoder.rs` is the only new public authoring layer. It owns opaque handles, ordered declarations, deterministic allocation and static validation, then lowers into the existing `DescriptorSet`; existing OBU/model/parser APIs remain the exact low-level surface. The built value is immutable and cannot write frames until Plan 04-02 attaches a sink.

**Tech Stack:** Rust 1.85, existing dependency-free model/OBU/sequence layers, `Vec` only for output-affecting ordered collections.

**Spec:** `.planning/phases/04-parallax-facing-api/04-CONTEXT.md`.

## Global Constraints

- IAMF v1.1.0; no Parallax crate, identifiers, preview/export state, rendering, DSP, resampling or codec implementation.
- Handles are caller-local opaque newtypes; IDs are allocated only by the builder and exposed only by its manifest.
- Codec Configs and Audio Elements serialize in normative ID order; Mix Presentations preserve declaration order.
- Profile selection is maximum of per-Presentation minima, never a sequence-wide union.
- Keep `AudioElementType::scene_based` crate-private; this layer alone may lower the supported Ambisonics-mono declaration.
- Reserved layouts remain typed build errors; known expanded layouts receive explicit normative channel counts.
