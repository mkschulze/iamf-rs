# Phase 4 Plan 02: Typed Frames and Transactional Streaming

> **For agentic workers:** REQUIRED SUB-SKILL: Use `superpowers:executing-plans` task-by-task.

**Goal:** Let an immutable encoder emit complete validated temporal units over `W: Write` from LPCM bytes or caller-encoded FLAC/Opus access units.

**Architecture:** The high-level API translates typed input once into the existing `TemporalUnit`, then delegates byte emission to `SequenceWriter`. It preflights the complete unit before that delegation, so bad input emits no bytes; a sink failure remains the existing poisoned-writer state.

**Tech Stack:** Rust 1.85, `SequenceWriter<W>`, existing `AudioFrame`, `ParameterBlock`, codec configs, no codec crates.

**Spec:** `.planning/phases/04-parallax-facing-api/04-CONTEXT.md`.

## Global Constraints

- Accept pre-encoded FLAC/Opus access units verbatim and LPCM payload bytes; never encode/decode/resample them.
- Accept pre-decimated IAMF blocks only when a matching declared definition governs their id/type/rate/duration; do not author demixing/recon-gain values.
- A temporal unit covers each declared substream exactly once, retains declared order, and uses one consistent trim plan.
- `start(W)` writes frozen descriptors; `finish(self)` consumes the writer and returns the sink; partial sink failure poisons subsequent operations.
