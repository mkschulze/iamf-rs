# Phase 4 Plan 03: Shared Elements and Public Contract Fixtures

> **For agentic workers:** REQUIRED SUB-SKILL: Use `superpowers:executing-plans` task-by-task.

**Goal:** Prove the public surface models Parallax’s filtered delivery contract without importing Parallax and emits valid shared descriptors/frames.

**Architecture:** Fixture builders use only `iamf::encoder` exports. They create model-shaped local delivery data, filter it before calling the encoder, and assert bytes/descriptors/conformance afterward; no production adapter or Parallax type is introduced.

**Tech Stack:** Rust 1.85, public encoder API, existing fixture/conformance reference harnesses.

**Spec:** `.planning/phases/04-parallax-facing-api/04-CONTEXT.md`.

## Global Constraints

- One declared shared Audio Element produces one descriptor and one frame per temporal unit even when referenced by multiple Presentations.
- The public convenience path permits channel single-layer and Ambisonics mono only; no public low-level scene constructor or projection/scalable authoring.
- Gain, labels, layouts, caller-supplied loudness and valid pre-decimated blocks are exercised as data, never calculated by this crate.
- Fixtures run structural/deterministic gates and the applicable external codec conformance gate.
