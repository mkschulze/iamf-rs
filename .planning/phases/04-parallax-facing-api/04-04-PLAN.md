# Phase 4 Plan 04: Production Boundary and Consumer Handoff

> **For agentic workers:** REQUIRED SUB-SKILL: Use `superpowers:executing-plans` task-by-task.

**Goal:** Freeze and document the dependency-free public API contract with a reproducible no-default-features proof.

**Architecture:** Tests inspect the compiled public surface and Cargo graph; documentation tells a Parallax adapter exactly what it owns versus what `iamf-rs` owns. No optional integration feature or Parallax dependency is introduced.

**Tech Stack:** Rust 1.85, Cargo, existing lint/dependency canaries.

**Spec:** `.planning/phases/04-parallax-facing-api/04-CONTEXT.md`.

## Global Constraints

- `cargo build --no-default-features` must retain encoder and complete production bitstream API.
- Normal linked graph remains `iamf` plus proc-macro-only `thiserror`; no codec, DSP, integration or Parallax dependency.
- Documentation must say caller supplies a filtered immutable snapshot, pre-encoded frames, loudness and pre-decimated IAMF blocks.
- Decoder/rendering, timeline interpolation, source positions, container work and codec encoding remain explicitly out of scope.
