## Critical Anti-Patterns

| Pattern | Description | Severity | Prevention Mechanism |
|---------|-------------|----------|---------------------|
| Placeholder template ids | `build()` validates the caller's template, where ids are placeholders (the Parallax fixture sets `audio_element_id: 0` everywhere). A naive duplicate-id check broke the Parallax delivery. | blocking | Check duplicate **handles** first, then validate a handle-lowered clone (pattern from `260913-th8`). |
| "Decoder accepts it" as proof | `decoder_main` ignores trim placement and `pre_skip`, and filters on caller profiles. `libiamf` silently decodes 0 frames under a wrong profile. | blocking | Derive rules from pinned source and spec text. Test both the positive file and a control that must fail. |
| Stale IDE diagnostics | rust-analyzer/IDE repeatedly reported non-existent errors after executor commits. | advisory | Trust `cargo check --all-targets` / `cargo test --locked`, not IDE diagnostics. |
| Hanging `docker images` / no `timeout` binary | `docker images` hung during research; macOS has no `timeout` or `gtimeout`. | advisory | Wrap docker-dependent runs in a perl alarm, and report SKIPPED or TIMED OUT honestly. |
| Host-dependent FLAC/Opus CONF-05 | The local `iamfdec` on macOS has no FLAC/Opus (`dep_codecs_disabled: true`). | advisory | These skip by manifest design locally. Real FLAC/Opus CONF-05 runs only in the `reference` workflow on x86_64 Linux, which is guarded to fail if skipped there. |
| zsh modifiers in loops | `$c:available` inside an unquoted zsh loop expanded `:a` into a path. | advisory | Use `${c}` or quote it. |
