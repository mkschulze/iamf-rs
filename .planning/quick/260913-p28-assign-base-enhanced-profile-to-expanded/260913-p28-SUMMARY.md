# Quick 260913-p28 Plan 01: Base-Enhanced for expanded loudspeaker layouts Summary

`select_minimum_profile` now returns Base-Enhanced whenever a channel-based element's first layer is an expanded loudspeaker layout (after both 28-ceilings). The builder therefore writes `02 02` profile bytes, and pinned libiamf decodes the crate's expanded LFE and 9.1.6 files as 128 frames. Before the change the same files decoded to 0 frames.

## What changed

- `src/model/profile.rs`: the floor is `elements.iter().any(..)` with `matches!` on `layers.first()`. It uses no indexing and no arithmetic. It carries `// ref:` citations to iamf-tools `profile_filter.cc:165-171` and `obu_sequencer_base.cc:306-313`, libiamf `IAMF_decoder.c:643-648` and `:1402-1410`, and Eclipsa `FileExport.h:91-106`. The new module-doc section is "Expanded loudspeaker layouts need Base-Enhanced", and the fn docs gained a paragraph. No new ErrorKind.
- `tests/profile.rs`:
  - `elements_totalling` is deleted and replaced by `ambisonics_element(n)`, which uses the public builder.
  - The six channel-limit tests keep their names and outcomes: 16 Simple, 17 Base, 18 Base, 19 BE, 28 BE, 29 error.
  - The 9.1.6-alone test was renamed to `..._selects_base_enhanced_when_alone`.
  - New tests: `every_named_expanded_layout_alone_selects_base_enhanced` (13 expanded + 10 standard controls), `ambisonics_plus_an_expanded_lfe_selects_base_enhanced_not_base` and `ceilings_are_checked_before_the_expanded_floor`.
  - The 28 x 9.1.6 test is unchanged.
- `tests/encoder_builder.rs`:
  - `two_presentation_builder` now uses two TOA elements (new helper `add_toa_element`). It still asserts Simple, and its comment now notes Disagreement 1.
  - New tests: the tracer, `every_named_expanded_layout_builds_a_base_enhanced_header` (literal 23 rows, 2/2 vs 0/0) and `a_stereo_presentation_and_an_expanded_presentation_make_a_base_enhanced_sequence`.
- `tests/conformance.rs`: `expanded_layout_elements_decode_through_libiamf` plus the helper `expanded_layout_sequence`. The helper is 48 kHz / 16-bit LE / 128 samples, uses Sound System A, and deliberately bypasses `OutputLayout::for_layout`.
