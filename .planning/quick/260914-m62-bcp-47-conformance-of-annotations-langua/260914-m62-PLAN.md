RFC 5646 section 2.1 facts the grammar must honour (from RESEARCH.md, with one research example corrected during
planning, see the last bullet):
- `Language-Tag = langtag / privateuse / grandfathered`. `langtag = language ["-" script] ["-" region] *("-" variant)
  *("-" extension) ["-" privateuse]`.
- `language = 2*3ALPHA ["-" extlang] / 4ALPHA / 5*8ALPHA`. `extlang = 3ALPHA *2("-" 3ALPHA)`, allowed only after a 2-3
  letter language. `script = 4ALPHA`. `region = 2ALPHA / 3DIGIT`. `variant = 5*8alphanum / (DIGIT 3alphanum)`.
- `extension = singleton 1*("-" (2*8alphanum))`. `singleton` is any single alphanumeric except `x`/`X`.
  `privateuse = "x" 1*("-" (1*8alphanum))`.
- Irregular grandfathered tags (a whole-tag, case-insensitive literal list, because they do not match `langtag`):
  `en-GB-oed, i-ami, i-bnn, i-default, i-enochian, i-hak, i-klingon, i-lux, i-mingo, i-navajo, i-pwn, i-tao, i-tay,
  i-tsu, sgn-BE-FR, sgn-BE-NL, sgn-CH-DE`. The regular grandfathered tags (`art-lojban`, `zh-min-nan`, ...) already
  match `langtag` and need no list.
- Correction to the RESEARCH.md reject example `en-Latn-zh`: `zh` after a script is a two-letter region, so that tag is
  well-formed. The reject case for "extlang after script" is `en-Latn-yue`.
