## Deviations from Plan

- **[Rule 2] Scan failure maps to exit 2.** If `find | sort | xargs perl` fails under `pipefail`, the script exits 2 with a message. It does not propagate xargs' raw status (for example 123). That way prove-guards' "census itself broke" branch really fires. `xargs -r` guards against an empty file list.
- The prove-guards summary printf uses an `EXPECTED_PASS` variable. The gate keeps the literal `-ne 9` because Task 2's verify greps for it.

Otherwise the plan was executed as written.

## Known limits (documented in the script header)

`/* */` block comments and trailing `//` comments after code are not stripped, so they can produce a false positive that fails loudly. Attributes generated by a macro are invisible to the textual scan.
